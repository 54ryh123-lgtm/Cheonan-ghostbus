# 천안 유령버스 — 데이터 분석 및 실시간 버스정보 개선 방안

2026 천안시 AI 공모전 출품작. 국토교통부 버스도착정보를 직접 수집·분석해,
"곧 도착"으로 표시된 버스가 갱신 없이 사라지는 **유령버스 현상**을 정량 진단하고
소멸 위험을 예측하는 AI 모델과 신뢰도 알림 서비스를 제안한다.

---

## 문제 정의
천안은 인구 71만·2026년 AI 특화 시범도시이지만, 시민이 보는 실시간 버스 도착정보가
"곧 도착"으로 떴다가 **도착 정보가 멈춘 채 목록에서 사라지는(유령버스)** 현상이 반복된다.
AI 교통 서비스의 전제는 정확한 실시간 데이터인데, 그 기반 정보부터 신뢰할 수 없다는 문제의식에서 출발했다.

## 분석 목표
- "버스는 왜 늦는가"가 아니라 **"그 도착정보를 믿을 수 있는가"**를 정량적으로 측정
- 유령버스(소멸)를 엄격히 정의하고, 언제·어디서·어느 노선에 몰리는지 규명
- 소멸을 사전에 예측하는 AI 모델을 만들어 실시간 알림 서비스로 제안

## 데이터
- 국토교통부 TAGO 버스도착정보 API를 **30초 간격으로 로깅** (매 순간 '도착 예정 버스 목록' 스냅샷)
- 2026년 7월 평일 **10일** · 3개 거점(종합터미널·천안역동부광장·한기대) · 낮/오후 시간대
- 통합 23,710행. 차량 개별 ID가 없어 노선 단위로만 추적(실제 도착 여부는 미확인)

## 분석 과정
1. **전처리** — 10일 로그 통합, 날짜·시간대 부여, 설계 외 파일 제외
2. **유령버스 정의** — 곧도착(남은정거장 ≤ 2, 예정초 ≤ 180)으로 표시되던 노선이
   ① 다음 스냅샷에서 사라지고 ② 사라지기 직전 예정초 > 스냅샷간격+20초
   ③ 세션 끝까지 재등장 없음 ④ 세션 종료 3분 이내 제외 — 4조건 충족 시 소멸
3. **집계** — 정류장·노선·시간대별 소멸률, 지속시간, 도착예정초 갱신 실태
4. **AI 모델** — RandomForest로 소멸 여부 예측, Leave-One-Day-Out 교차검증
5. **데모** — 정류장·노선·시간대 입력 시 소멸 위험등급(신뢰/주의/불신)을 내는 웹 서비스

## 핵심 결과
- 도착예정초의 **97%가 갱신 없이 고정** → 유령버스의 근본 원인
- 곧도착 정보의 **28.9%가 소멸**(BIS 신뢰도 지수 71.1%), 소멸의 과반이 천안역에 집중
- 소멸률 **천안역 39% vs 종합터미널 19%**(약 2배) — 가장 혼잡한 터미널이 오히려 최저 → 혼잡이 원인 아님
- 소멸 예측 모델 **10일 교차검증 평균 AUC 0.81 (±0.06)**

## 의의 및 한계
- **의의**: 버스 정시성이 아니라 '도착정보의 신뢰도'를 국내 최초로 정의·측정했고,
  소멸이 무작위가 아닌 특정 위치·노선에 쏠린 예측 가능한 패턴임을 데이터와 모델로 입증했다.
